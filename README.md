# Rezka Progress

Расширение Chrome для локального каталога фильмов и сериалов HDRezka. Manifest V3, без сборки и внешних зависимостей.

## Возможности

- Последние 10 просмотров, полный каталог, избранное, архив и скрытые записи.
- Сохранение названия, года, озвучки и постера при открытии страницы; времени просмотра — после запуска видео.
- Поиск с поддержкой опечаток, редактирование прогресса и корзина с восстановлением.
- Импорт открытой страницы «Досмотреть» без массовых запросов к страницам сериалов.
- Отправка прогресса выбранного просмотренного сериала в текущий аккаунт по кнопке.
- Основное зеркало или автоматический выбор текущего/последнего открытого домена.
- Полная резервная копия `.json.gz`, поддержка старых JSON-копий, светлая и тёмная темы.

## Установка

1. Склонируй репозиторий или скачай и распакуй его архив.
2. Открой `chrome://extensions` и включи режим разработчика.
3. Нажми «Загрузить распакованное расширение» и выбери папку с `manifest.json`.
4. Обнови открытые вкладки сайта.

После обновления файлов нажми кнопку обновления расширения в `chrome://extensions` и перезагрузи вкладки сайта. Перед переносом расширения в другую папку сохрани полную копию через настройки: другая папка может получить другой ID расширения и отдельное хранилище. Затем восстанови копию в новой установке.

## Провайдер и зеркала

Поддерживаются `hdrezka-home.tv`, `rezka.ag`, `www.rezka.ag`, `hdrezka.mn`, `rezka.si`.

В настройках HDRezka можно выбрать основное зеркало. Адреса произведений хранятся без домена; при переходе используется выбранное зеркало. Режим «Авто» использует текущую вкладку HDRezka или последнее открытое поддерживаемое зеркало. Фоновой проверки доступности доменов нет. Авторизация между зеркалами не переносится.

## Данные и ограничения

Данные хранятся в `chrome.storage.local`. Изображения загружаются с CDN сайта по сохранённым ссылкам. Импорт читает только DOM открытой страницы «Досмотреть»; автоматический обход страниц отключён. ID озвучки уточняется по доступной разметке при обычном открытии сериала. Без однозначного ID используется штатная ссылка продолжения сайта.

Отправка прогресса выполняется только по действию пользователя с текущей авторизацией страницы. При 403/429 последовательность отправок прекращается; автоматических повторов нет. Расширение не обходит ограничения сайта. Разметка и плеер сайта могут измениться.

Полная копия включает каталог, прогресс, импорт, адреса постеров, настройки, корзину и выбранное зеркало. Восстановление полной копии заменяет текущее состояние. Старые копии прогресса объединяются по дате. Cookies, пароли, файлы изображений и браузерный кеш не входят в копию.

Проект не связан с администрацией HDRezka.

## Разработка

Нужны Chrome 120+ и Node.js 22+ для тестов.

```sh
node --test extension.test.mjs
```

- `content.js` — чтение карточки и отслеживание видео.
- `account.js`, `parser.js` — работа с текущей страницей аккаунта и разметкой сайта.
- `background.js` — хранение данных и обработка команд.
- `history.mjs` — каталог, поиск, зеркала и восстановление данных.
- `backup.mjs` — формат копий и gzip.
- `popup.html`, `popup.js`, `theme.js` — интерфейс.

В тестах используются фикстуры и модели Chrome API, реальные аккаунты и сетевые запросы не требуются. Проверки не заменяют ручное тестирование установленного расширения.
