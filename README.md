# Rezka Progress

История и прогресс просмотра для Chrome. Поиск, избранное и резервные копии.

## Установка

1. Скачай ZIP из [последнего релиза](https://github.com/reslear/rezka-progress/releases/latest) и распакуй его.
2. Открой `chrome://extensions` и включи режим разработчика.
3. Нажми «Загрузить распакованное расширение» и выбери папку с `manifest.json`.
4. Обнови вкладки сайта.

Chrome 120+. ZIP нужно распаковать: напрямую Chrome его не устанавливает.

При обновлении замени файлы в той же папке и обнови расширение. Перед переносом в другую папку сохрани резервную копию в настройках.

## Проверка

```sh
node --test extension.test.mjs
```
